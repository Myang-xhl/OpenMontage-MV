# Seedance Prompt 写作指南

本指南融合了 Seedance 2.0 官方提示词优化规范，用于指导生成高质量工程化prompt。

> 好的提示词不是文案型形容，而是工程型指令：谁、在什么场景、做什么动作、镜头如何运动。

---

## 一、八大核心要素公式

每个分镜的Seedance prompt遵循以下结构：

```
[精准主体] + [动作细节] + [场景环境] + [光影色调] + [镜头运镜] + [视觉风格] + [画质] + [约束条件]
```

> 前2项必填，后6项按需补全。缺失时按默认策略自动补全。

### 各部分说明

| # | 部分 | 作用 | 字数建议 | 是否必需 |
|---|------|------|---------|---------|
| 1 | 精准主体 | 人物外观关键特征（从人物库提取） | 20-40字 | **必填** |
| 2 | 动作细节 | 肢体细化+程度量化+情绪具象外化 | 15-30字 | **必填** |
| 3 | 场景环境 | 具体环境、时间、天气、**氛围质感**（核心） | 30-50字 | 是 |
| 4 | 光影色调 | 色调方向 + 光源 + **氛围光影互动** | 15-30字 | 是 |
| 5 | 镜头运镜 | 景别 + 角度 + 运镜方式（一镜一运镜） | 10-20字 | 是 |
| 6 | 视觉风格 | 定调整体视觉风格和氛围 | 10-20字 | 是 |
| 7 | 画质 | 清晰度要求（默认画质包） | 10-15字 | 是 |
| 8 | 约束条件 | 兜底防崩约束包 | 15-30字 | 是 |

总字数建议：80-200字/shot。

## 五、强制兜底约束包

每个prompt末尾**必须挂载**以下约束包，确保画面质量与防崩：

### 画质包（必挂）
```
高清，细节丰富，电影质感，色彩自然，光影柔和
```
> 简单场景可压缩为短句"高清电影质感"

### 稳定包（必挂）
```
人物面部稳定不变形、五官清晰、动作连贯自然，不僵硬，无穿模无卡顿
```

### 字幕兜底（必挂）
```
保持无字幕，避免生成任何文字或字幕
```

### 水印/Logo兜底（必挂）
```
不要生成水印，不要生成Logo
```

### 双胞胎兜底（双人镜必挂）
```
视频全程禁止出现外形、着装、配饰完全一致的人物，禁止生成同款分身、双胞胎效果
```

### 物理约束（按需）
```
人物比例符合现实世界物理规律
```

### 组合用法示例

**人物镜末尾**：
```
高清电影质感，人物面部稳定不变形、五官清晰、动作连贯自然，保持无字幕，不要生成水印，不要生成Logo。
```

**双人镜末尾**：
```
高清电影质感，人物面部稳定不变形、五官清晰、动作连贯自然，保持无字幕，不要生成水印，不要生成Logo，视频全程禁止出现外形、着装、配饰完全一致的人物，禁止生成同款分身、双胞胎效果。
```

**空镜末尾**：
```
高清电影质感，画面稳定无变形，保持无字幕，不要生成水印，不要生成Logo。
```

## 六、动作描述规范（Seedance 2.0 核心要求）

### 肢体细化 + 程度量化
- 手/腿/头/肩背 + 幅度/速度/力度
- 例："双手插在卫衣口袋里"、"肩膀微微颤抖"、"手指攥紧衣角"

### 优先低缓连续小动作
- 规避狂奔/大跳/剧烈翻滚等高爆发动态
- 推荐动作：缓步行走、微微转头、抬手放下、低头看手机、靠墙站立
- 补充动作过渡衔接：前后惯性承接（如"借着转身惯性顺势抬手"）

### 情绪具象外化
用具体身体细节代替"悲伤/愤怒"等抽象词：

| 情绪 | 具象描写 |
|------|----------|
| 悲伤 | 肩膀微微颤抖、眼眶泛红、手指攥紧衣角 |
| 紧张 | 手指无意识攥紧、呼吸微顿、目光闪躲 |
| 释然 | 肩膀缓缓松下、嘴角微扬、闭眼深呼吸 |
| 痴迷 | 目光追随、嘴角苦涩微笑、身体前倾 |
| 冷漠 | 侧脸看向窗外、手指无意识拨弄杯子、不对视 |
| 压抑 | 双手捂脸后放下、仰头看天、嘴唇颤抖 |

## 六、Prompt写作注意事项

### DO - 应该做的

1. **风格前置**：在prompt开头明确整体风格
2. **时间线分段**：对于较长分镜（>5秒），可用"0~2秒...3~5秒..."分段描述
3. **具体描述**：人物外观、动作、环境都要具体，避免模糊
4. **场景氛围感为核心**：每个prompt必须让读者能"感受到"场景的空气、光线、温度和情绪，而非仅"看到"画面。具体要求：
   - 描写空气质感（雾气/雨雾/烟尘/干燥/潮湿）
   - 描写光线状态（直射/散射/逆光/侧光/漫射光）
   - 描写环境动态（风吹树叶/雨滴落地/灰尘飞舞）
   - 描写色温层次（暖光/冷光/混合光/色温过渡）
   - 描写空间纵深（前景/中景/远景的环境层次）
5. **感官细节**：通过视觉暗示声音、温度、气味等
6. **中文为主**：Seedance 2.0对中文prompt理解最佳
7. **人物一致**：同一场景的人物描述保持一致
8. **空镜氛围加倍**：空镜prompt不包含人物描述，但场景氛围感描写需更加充分，用氛围叙事
9. **一镜一运镜**：单镜头只指定1种运镜方式（推/拉/摇/移/固定/跟拍择一），禁止叠加
10. **动作优先低缓**：优先低缓连续小动作，规避狂奔/大跳/剧烈翻滚等高爆发动态
11. **情绪具象外化**：用具体身体细节代替"悲伤/愤怒"等抽象词（如悲伤→"肩膀微微颤抖、眼眶泛红"）
12. **强制兜底**：每个prompt末尾必须挂载画质包+稳定包+字幕兜底+水印Logo兜底；双人镜追加双胞胎兜底

### DON'T - 不应该做的

1. **不要包含文字/字幕**：Seedance无法生成清晰的文字内容
2. **不要使用不确定词汇**：如"可能"、"也许"、"大概"
3. **不要描述UI界面**：如手机屏幕、电脑界面等复杂UI
4. **不要过长**：单个prompt不超过250字
5. **不要矛盾**：景别和运镜不要自相矛盾（如"大特写+大范围横摇"）
6. **不要忽略物理规律**：如"人物飞翔"除非歌曲风格允许
7. **不要运镜叠加**：单镜头不要同时出现推+摇或拉+移等叠加运镜
8. **不要高爆发动作**：避免狂奔、大跳、剧烈翻滚等高爆发动态
9. **不要抽象情绪词**：避免直接写"悲伤"、"愤怒"，改用具体身体细节描写

## 八、特殊字符规范

在prompt中需要表示声音信息时，使用以下统一符号：

| 信息类型 | 符号 | 示例 |
|------|------|------|
| 背景音乐 | `（）` | `（背景中播放着快节奏的摇滚乐）` |
| 音效 | `<>` | `<远处传来狗叫声>` |
| 台词 | `{}` | `{你好，世界}` |
| 字幕/标题 | `【】` | `【第一章：启程】` |

> MV分镜中一般不使用台词和字幕符号（歌词作为画面外音轨存在），但可在蒙太奇空镜中使用音效符号增强氛围。

