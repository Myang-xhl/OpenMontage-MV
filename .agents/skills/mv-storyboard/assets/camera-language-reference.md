# 镜头语言参考表

本参考表用于分镜编排时选择合适的镜头语言，包含景别、角度、运镜三大维度的完整术语库及适用场景。

---

## 一、景别（Shot Size）

景别决定画面中人物与环境的比例关系，直接影响观众的心理感受。

| 景别 | 英文 | 画面范围 | 情感功能 | 适用场景 |
|------|------|---------|---------|---------|
| 大远景 | Extreme Long Shot | 人物极小，环境占主导 | 交代宏大环境、渺小感、史诗感 | 开场空镜、壮丽风景、城市鸟瞰 |
| 远景 | Long Shot / Wide Shot | 可见人物全身及周围环境 | 交代场景、人物与环境关系 | 场景建立、人物登场、群体画面 |
| 全景 | Full Shot | 人物全身可见 | 展示人物整体造型和肢体语言 | 走路、舞蹈、全身动作 |
| 中景 | Medium Shot | 人物腰部以上 | 日常对话感、亲和力 | 对话场景、日常互动、叙事推进 |
| 近景 | Medium Close-Up | 人物胸部以上 | 拉近距离、关注表情 | 情感表达、对话反应、演唱画面 |
| 特写 | Close-Up | 人物面部为主 | 强调情绪、捕捉微表情 | 情感高潮、关键反应、细节捕捉 |
| 大特写 | Extreme Close-Up | 眼睛、嘴唇等局部 | 极致细节、强烈情绪冲击 | 极致情绪、物件细节、转场匹配 |

### 景别选择原则

- **前奏/尾奏**：多用大远景、远景（环境交代）
- **主歌**：多用中景、近景（平稳叙事）
- **副歌**：多用近景、特写（情感爆发）
- **间奏空镜**：多用远景、大远景或微距特写
- **情感转折**：景别突变（如中景→大特写）

## 二、角度（Camera Angle）

角度决定观众观察人物的视角，暗示人物心理地位和情感关系。

| 角度 | 英文 | 视觉效果 | 情感暗示 | 适用场景 |
|------|------|---------|---------|---------|
| 平视 | Eye Level | 与人物眼睛齐平 | 客观、平等、自然 | 日常叙事、对话、中性表达 |
| 仰视 | Low Angle | 从下往上拍 | 力量感、崇高感、压迫感 | 英雄登场、气场展示、力量表达 |
| 俯视 | High Angle | 从上往下拍 | 渺小感、脆弱感、孤独感 | 伤感段落、人物困境、孤独表达 |
| 鸟瞰 | Bird's Eye | 正上方垂直俯拍 | 全知视角、几何美感 | 城市鸟瞰、人群俯瞰、抽象画面 |
| 荷兰角 | Dutch Angle | 倾斜构图 | 不安、失衡、紧张 | 心理失衡、矛盾冲突、不安情绪 |

### 角度选择原则

- **平等关系**：双人对话用平视
- **权力关系**：强势方仰视，弱势方俯视
- **孤独表达**：俯视 + 大远景
- **英雄展示**：仰视 + 中景/全景
- **心理不安**：荷兰角 + 特写

## 三、运镜（Camera Movement）

运镜决定镜头的运动方式，直接影响画面的节奏感和动态感。

| 运镜方式 | 英文 | 运动描述 | 情感效果 | 适用场景 |
|---------|------|---------|---------|---------|
| 固定 | Static / Fixed | 镜头不动 | 稳定、沉静、凝视 | 静态情绪、空镜、对峙 |
| 推 | Push / Dolly In | 镜头向主体靠近 | 聚焦、紧张感、情绪升温 | 情感递进、发现、惊讶 |
| 拉 | Pull / Dolly Out | 镜头远离主体 | 疏离、揭示、释然 | 离别、结尾、揭示全貌 |
| 摇 | Pan / Tilt | 镜头原地转动 | 展示空间、跟随视线 | 全景扫视、视线跟随、环境展示 |
| 移 | Track / Truck | 镜头整体平移 | 跟随感、流动感 | 行走跟拍、平行移动、空间展示 |
| 跟 | Follow | 跟随人物运动 | 沉浸感、参与感 | 行走、奔跑、追逐 |
| 升降 | Crane / Boom | 镜头垂直运动 | 高度变化、视角转换 | 俯瞰升起、仪式感、宏大展示 |
| 环绕 | Orbit / Arc | 围绕主体旋转 | 展示全貌、仪式感、浪漫 | 人物展示、浪漫时刻、高潮段落 |
| 手持 | Handheld | 模拟手持晃动 | 纪实感、紧张感、临场感 | 纪实风格、紧张段落、街头风 |
| 一镜到底 | One Shot | 无剪辑连续运镜 | 连贯、沉浸、叙事流畅 | 场景转换、时间流逝、长叙事 |

### 运镜修饰词

在运镜方式前添加修饰词控制速度和质感：

| 修饰词 | 效果 | 示例 |
|--------|------|------|
| 缓慢 | 柔和、情绪沉淀 | 缓慢推进、缓慢横摇 |
| 匀速 | 自然、平稳 | 匀速平移、匀速升降 |
| 快速 | 紧张、冲击力 | 快速推进、快速横摇 |
| 急速 | 爆发、惊吓 | 急速拉近 |
| 微微 | 细腻、微妙 | 微微上移、微微推进 |

### 运镜选择原则

- **主歌（平稳叙事）**：固定、缓慢推、缓慢移
- **副歌（情感爆发）**：快速推、环绕、升降、手持
- **间奏（过渡转换）**：拉、摇、移、一镜到底
- **空镜（氛围营造）**：缓慢横摇、微距、延时
- **离别/结尾**：缓慢拉、升降上升
- **相遇/高潮**：推、环绕

## 四、镜头组合模式

### 4.1 情感升温模式
```
中景(固定) → 近景(缓慢推) → 特写(快速推) → 大特写(固定)
```
适用：副歌段落、情感高潮

### 4.2 环境交代模式
```
大远景(固定) → 远景(缓慢横摇) → 全景(缓慢推) → 中景(固定)
```
适用：前奏、场景转换

### 4.3 离别疏离模式
```
近景(固定) → 中景(缓慢拉) → 全景(缓慢拉) → 大远景(固定)
```
适用：分手段落、离别场景

### 4.4 蒙太奇快切模式
```
特写(快速推) → 近景(手持) → 特写(固定) → 近景(快速横摇) → 特写(固定)
```
适用：快节奏段落、副歌高潮

### 4.5 意境流动模式
```
大远景(缓慢横摇) → 远景(缓慢移) → 中景(缓慢推) → 特写(固定) → 大远景(缓慢拉)
```
适用：古风段落、慢板抒情

## 五、转场方式

| 转场 | 效果 | 适用场景 |
|------|------|---------|
| 硬切 | 直接切换，干脆利落 | 节奏快切、段落切换、蒙太奇 |
| 叠化 | 前后画面交叠渐变 | 时间流逝、回忆闪回、梦境 |
| 闪白 | 白光闪过切换 | 高潮爆发、记忆闪回、节奏点 |
| 黑场 | 画面渐黑再亮 | 段落结束、时间跳转、情绪停顿 |
| 匹配剪辑 | 相似构图衔接 | 场景转换、时空跳跃、视觉连贯 |
| 无 | 最后一个分镜无转场 | 结尾 |

### 转场选择原则

- 同一场景内：硬切为主
- 不同场景转换：叠化或匹配剪辑
- 情感爆发点：闪白
- 段落间隔/时间跳转：黑场
- 快节奏段落：硬切

## 六、节奏控制

| 节奏类型 | 描述 | 适用场景 |
|---------|------|---------|
| 快切 | 分镜短促，快速切换 | 快节奏副歌、蒙太奇段落 |
| 慢镜头 | 画面减速，时间拉长 | 情感高潮、关键瞬间、浪漫时刻 |
| 正常 | 正常速度 | 日常叙事、对话场景 |
| 延时 | 时间加速 | 时间流逝、环境变化、空镜 |
| 慢动作 | 人物动作减速 | 情感爆发、雨滴/花瓣等细节 |

### 节奏选择原则

- 副歌段落可混合使用快切 + 慢动作
- 主歌段落以正常节奏为主
- 间奏空镜可用延时
- 情感高潮用慢镜头
- 歌曲结尾可渐慢
