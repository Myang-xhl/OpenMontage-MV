- 每个 director 技能文件采用固定章节结构：When To Use → Prerequisites（表格列出工具/层3引用/Schema）→ Process（编号步骤）→ Checkpoint → Self-Review
- 所有阶段产物通过 `schemas/artifacts/<name>.schema.json` 进行 JSON Schema 校验，校验失败视为 critical 发现
- 检查点统一通过 `lib.checkpoint.write_checkpoint(pipeline_dir, project_name, stage, status, artifacts, metadata)` 写入，状态值限定为 completed/in_progress/awaiting_human 之一
- 全流水线默认 `human_approval_default: false` 自动运行，检查点仅用于 Feed Backlot 看板与恢复，不阻塞流程
- 每个 director 的 Self-Review 段落严格对照该阶段的 `review_focus` 清单逐项核对，而非泛泛复查
- Layer 3 业务规则（如 mv-storyboard SKILL.md、seedance-prompt-guide.md）通过引用而非复述的方式使用，禁止在 director 中重新声明其约束
