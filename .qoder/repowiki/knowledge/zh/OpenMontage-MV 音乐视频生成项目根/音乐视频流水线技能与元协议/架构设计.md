本模块由两类 Markdown 技能文件组成，全部以指令驱动而非代码实现：
- `meta/` 存放跨阶段的元协议：`checkpoint-protocol.md` 统一规定检查点的写入时机、状态机（completed/in_progress/awaiting_human）、人工审批门控（human_approval_default）与恢复流程；`reviewer.md` 规定每阶段产物的 CHAI 三原则（准确/完整/建设性）评审流程、决策日志审计与分阶段自检规则。
- `pipelines/music-video/` 按流水线顺序组织七个 director 技能（idea → proposal → storyboard → assets → edit → compose → publish），每个文件遵循相同模板：When To Use、Prerequisites（工具/层3引用/Schema）、Process（步骤化操作）、Checkpoint（调用 lib.checkpoint.write_checkpoint）、Self-Review（对照 review_focus）。所有导演技能均通过 `.agents/skills/mv-storyboard/SKILL.md` 等 Layer 3 文档获取权威规则，自身不重复定义业务逻辑。
依赖方向单向向下：director 技能依赖 meta 协议与 schemas/artifacts/*.schema.json 进行产物校验，并通过 `lib.checkpoint` 与 Backlot board 交互，不反向依赖上层编排器。
