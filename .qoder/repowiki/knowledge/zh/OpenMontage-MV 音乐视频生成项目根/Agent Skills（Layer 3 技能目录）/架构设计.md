该模块是 OpenMontage 三层架构中的 Layer 3（.agents/skills/），与 Layer 2（skills/）并列，由 backlot/agent/tools.py 中的 scan_skills() 统一扫描发现：每个技能是一个子目录，必须包含一个 SKILL.md 清单文件，清单支持 YAML frontmatter（description 字段用于描述，否则回退到首个标题）。scan_skills() 会同时遍历 .agents/skills/ 和 skills/，将两者合并为 skill_id -> {description, path} 的目录表，再由 list_skills/load_skill 工具对外暴露。tools/base_tool.py 通过 ToolBase.agent_skills 字段声明依赖的技能名，编排器据此自动加载相关 API 知识。本目录本身不含代码，仅作为纯文档型技能包的宿主。
