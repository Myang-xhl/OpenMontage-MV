本模块是纯 Python 包 `lib/`，各文件职责单一、无子包，通过显式导入形成依赖方向：
- 配置层：`config_model.py` 基于 Pydantic BaseModel 定义 `OpenMontageConfig`（含 checkpoint/output/paths 子配置），从 `config.yaml` 加载并支持默认值；`env_loader.py` 通过 python-dotenv 加载 `.env` 并提供 `get_env`/`require_env`。
- 路径层：`paths.py` 暴露 `REPO_ROOT` 和可被 `OPENMONTAGE_PROJECTS_DIR` 覆盖的 `PROJECTS_DIR`，作为全仓唯一真实路径来源，被 `checkpoint.py`、`events.py` 等直接引用。
- 流水线层：`pipeline_loader.py` 从 `pipeline_defs/*.yaml` 读取清单，使用 `schemas/pipelines/pipeline_manifest.schema.json` + jsonschema 校验，并通过 `lru_cache` 缓存 schema 与 manifest 读取；提供 `load_pipeline_readonly` 供热路径复用。
- 检查点层：`checkpoint.py` 负责项目初始化、写入/读取/归档检查点（JSON + history 目录）、决策日志合并、以及基于 manifest 的人审门控（`human_approval_default`）；通过 `schemas/checkpoints/checkpoint.schema.json` 校验结构。
- 事件层：`events.py` 以单行 JSONL 追加写 `events.jsonl`，线程内加锁但跨进程无同步，失败静默丢弃，保证可观测性不破坏生产。
- 媒体配置：`media_profiles.py` 用 frozen dataclass 定义平台 MediaProfile 常量及 FFmpeg 输出参数生成。
依赖方向单向向下：checkpoint → pipeline_loader / paths；events → paths；config_model 独立；media_profiles 独立。所有外部 I/O（YAML/JSON/文件系统）均通过 pathlib 与标准库完成，无全局状态。
