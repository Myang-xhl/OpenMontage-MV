- 所有对文件系统或外部 I/O 的操作都通过 `asyncio.to_thread` 放入线程池，避免阻塞异步事件循环
- 状态推导函数遵循「never block, never break」原则：JSON 解析失败、文件缺失等均降级返回空值而非抛异常
- SSE 端点统一使用 `_sse()` 序列化 payload，并以 heartbeat（15s 超时）维持连接存活
- 项目 ID 校验集中在 `_safe_project_dir`，拒绝包含 `/\:` 的路径以防止目录穿越
- UI 页面通过 `_ui_html(name, assets)` 模板化加载，并为每个静态资源附加 `?v=<mtime>` 实现强制缓存失效
