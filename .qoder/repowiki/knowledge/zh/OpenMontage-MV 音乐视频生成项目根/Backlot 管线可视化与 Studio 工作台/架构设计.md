backlot 采用「CLI 入口 → FastAPI 服务器 → 只读状态层 + Agent 会话」的分层架构：
- `__main__.py` 提供 `open`/`serve`/`studio` 三个子命令，`open` 会探测 `/api/health` 并自动拉起后台 `serve` 进程，实现幂等启动。
- `server.py` 构建 FastAPI 应用，注册三类路由：项目状态 API（`/api/project/{id}/state`、`/api/projects`）、SSE 事件流（`/api/project/{id}/events`、`/api/library/events`、`/api/chat/{id}/events`）以及静态 UI 页面（`/`、`/p/{id}`、`/studio`、`/preview/{id}`）。`ChangeHub` 基于 asyncio.Queue 按 project_id 过滤 fan-out，watchfiles 监听 `projects/` 目录变更并去重后发布。
- `state.py` 是纯只读的状态推导层，从 checkpoint/history/artifacts/events 等文件系统结构合成 BoardState，被 server 的 API 端点调用；`summarize_project` 用于库视图缓存。
- `agent/` 子模块实现 Studio 聊天工作台的 Agent 循环：`harness.py` 驱动模型调用、工具执行、上下文压缩与错误恢复，通过 `sessions.py` 暴露 Session 协议，由 server 的 `/api/chat/*` 路由桥接。
- `ui/` 存放纯前端 HTML/CSS/JS，通过 `_ui_html` 注入带版本戳的静态资源路径，并由 `StaticFiles` 挂载 `/ui`。
- 所有对外依赖（PROJECTS_DIR、REPO_ROOT）来自 `lib.paths`，保证单点可配置。
