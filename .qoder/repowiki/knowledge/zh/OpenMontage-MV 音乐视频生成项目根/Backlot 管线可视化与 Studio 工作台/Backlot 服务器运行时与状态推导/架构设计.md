模块由三个文件构成清晰的三层结构：
- `__main__.py`：CLI 入口，通过 argparse 暴露 `open`/`serve`/`studio` 子命令；`open` 会探测 `/api/health` 并在必要时用 `subprocess.Popen` 后台拉起 `uvicorn` 进程，日志写入 `.studio/server.log`（5MB 轮转）。
- `server.py`：基于 FastAPI 的 HTTP 服务，`create_app()` 集中注册所有路由，包括项目列表/状态 API、SSE 事件流（`/api/project/{id}/events` 与 `/api/library/events`）、Studio 聊天会话管理、`/thumb` 缩略图与 `/media` 媒体直出、以及静态 UI 页面挂载。核心是 `ChangeHub` 类——按 project_id 过滤的 asyncio.Queue fan-out，配合 `watchfiles.awatch` 后台任务将文件系统变更去重后广播给订阅者。
- `state.py`：纯只读的状态推导层，从 `projects/<id>/` 目录中的 `checkpoint_*.json`、`artifacts/*.json`、`events.jsonl`、`scene_plan.json` 等文件构建 BoardState，遵循“never block, never break”原则，任何 IO/JSON 错误都降级返回空结构而不抛异常。
依赖方向单向：`server.py` → `state.py` + `backlot.agent.sessions`，CLI 仅依赖 `DEFAULT_PORT` 常量并通过 uvicorn 启动 server 模块，不直接导入业务逻辑。
