- 所有对磁盘 JSON 文件的读取都通过 `_read_json` 包装，失败时返回 None 而非抛出异常，保证板面永不崩溃。
- 对外暴露的路径参数（project_id、file_path）必须先经 `_safe_project_dir` 或相对路径校验，拒绝包含 `/\:` 及 `.` `..` 的非法输入，防止路径穿越。
- 耗时 I/O 操作（JSON 解析、Pillow/ffmpeg、`summarize_project`）统一通过 `asyncio.to_thread` 放入线程池执行，避免阻塞事件循环。
- SSE 端点遵循固定模式：先 yield `hello` 消息，然后 `wait_for(q.get(), timeout=SSE_HEARTBEAT_SECONDS)` 超时发送 heartbeat，收到消息后 drain 队列合并 burst，最后 yield change 消息。
- UI 页面通过 `_ui_html(name, assets)` 模板函数加载 HTML 并为每个静态资源追加 `?v=<mtime>` 查询参数以绕过浏览器缓存。
- 项目扫描忽略 `node_modules`、`.git`、`__pycache__`、`.cache` 等噪声目录，在 `_IGNORE_PARTS` 和 `SCAN_EXCLUDE` 两处集中声明。
