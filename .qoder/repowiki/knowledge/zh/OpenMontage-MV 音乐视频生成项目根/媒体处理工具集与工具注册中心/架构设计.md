模块以 `base_tool.py` 中的 `BaseTool` 抽象基类为核心，所有工具均继承该类并声明 `execute(inputs) -> ToolResult` 统一接口；`__init_subclass__` 通过 `_instrument_execute` 装饰器自动为每个 `execute` 注入 Backlot 事件埋点（start/finish/error），实现零侵入的可观测性。

- 分层结构：`base_tool.py` 定义工具契约（枚举 `ToolTier/ToolStability/ToolRuntime/Determinism`、数据类 `ResourceProfile/RetryPolicy/ToolResult`、依赖检查、成本估算、幂等键、子进程封装 `run_command`）；`tool_registry.py` 的 `ToolRegistry` 通过 `pkgutil.walk_packages` 自动扫描 `tools` 包下所有模块，反射发现 `BaseTool` 子类并实例化注册，暴露按 tier/capability/provider/status 查询及 `provider_menu_summary()` 等聚合报告方法。
- 能力子包：`analysis/`（ASS 歌词解析）、`audio/`（FFmpeg 混音/ducking/提取、本地音乐库扫描）、`enhancement/`（FFmpeg LUT 色彩分级）、`video/`（多片段拼接/转场/空间布局、Yinghe 异步视频生成 API）。每个子包仅包含若干具体工具类，无跨包调用，依赖方向单向指向 `base_tool`。
- 运行时代码路径：工具通过 `dependencies` 声明 `cmd:`/`binary:`/`env:`/`python:` 前缀的依赖，由 `check_dependencies` 统一校验；`.env` 文件在模块导入时由 `_load_dotenv()` 加载到 `os.environ`，供 API key 类工具使用。
- 输出规范：所有工具返回 `ToolResult`，包含 `success/data/artifacts/cost_usd/duration_seconds/model` 等字段，便于编排器统一消费。
