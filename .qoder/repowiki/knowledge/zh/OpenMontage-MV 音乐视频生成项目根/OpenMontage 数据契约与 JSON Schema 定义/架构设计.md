模块以纯声明式 JSON Schema 文件为核心资产，按领域划分为四个子目录：`artifacts/`（10 种制品类型如 brief、storyboard、asset_manifest 等）、`checkpoints/`（单一样本 checkpoint.schema.json）、`pipelines/`（pipeline_manifest.schema.json）和 `styles/`（playbook.schema.json）。每个子目录通过 `__init__.py` 暴露 Python 接口，其中 `artifacts/__init__.py` 提供 `load_schema`、`validate_artifact`、`list_schemas` 三个函数，使用 `jsonschema` 库在运行时加载对应 `.schema.json` 文件并执行验证；其他子目录的 `__init__.py` 目前为空占位。依赖方向单向：Python 代码仅读取 JSON 文件，Schema 文件之间通过 `$id` 命名空间（如 `openmontage/artifacts/brief`）进行标识，彼此不互相引用，保持解耦。
