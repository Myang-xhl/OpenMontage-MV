- 每个 JSON Schema 文件统一包含 `$schema`、`$id`、`title`、`description`、`type: object`、`required`、`properties` 和末尾的 `additionalProperties: false` 字段。
- Schema 文件的 `$id` 采用 `openmontage/<domain>/<artifact>` 三段式命名空间，便于跨域唯一标识。
- 字符串枚举字段通过 `enum` 显式列出允许值（如 status、category、checkpoint_policy 等），而非自由文本。
- 版本控制通过顶层 `version` 字段并使用 `const: "1.0"` 锁定，确保向后兼容性。
- 可选字段普遍提供 `default` 值或 `description` 注释，帮助使用者理解默认行为。
