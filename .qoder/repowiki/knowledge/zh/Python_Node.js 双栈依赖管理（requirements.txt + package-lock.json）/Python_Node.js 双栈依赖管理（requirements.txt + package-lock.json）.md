本仓库采用 Python 与 Node.js 双栈技术，分别通过 pip 的 requirements.txt 和 npm 的 package-lock.json 管理第三方依赖，未使用更现代的包管理器（如 Poetry、Pipenv、pnpm、yarn 等）。

**后端（Python）**
- 依赖声明：根目录 `requirements.txt`，仅列出运行时依赖（pyyaml、pydantic、jsonschema、python-dotenv、requests、fastapi、uvicorn、watchfiles），全部使用 `>=` 宽松版本约束，无精确锁定文件（无 `requirements.lock` / `poetry.lock`）。
- 安装方式：通过 `pip install -r requirements.txt` 安装；代码中未发现 vendoring 或私有 PyPI 源配置。
- 可选依赖：部分模块（如 `backlot/agent/harness.py`）在运行时 `import anthropic`，属于按需导入，未写入 requirements.txt，说明该依赖为可选。

**前端（MVAgent-Frontend）**
- 依赖声明：`MVAgent-Frontend/package-lock.json`（lockfileVersion 3），表明项目使用 npm 并提交了锁文件，确保构建可重现。
- 核心依赖：Vue 3 (`vue@^3.5.40`)、Pinia (`pinia@^4.0.2`) 作为运行时依赖；开发依赖包含 Vite、TypeScript、vue-tsc 等。
- 镜像源：从 resolved URL 可见使用了 `npmmirror.com`（淘宝镜像）。
- node_modules 被 `.gitignore` 忽略，符合标准实践。

**约定与约束**
- Python 侧未锁定具体版本号，存在上游变更导致环境不一致的风险。
- 前端侧通过提交 `package-lock.json` 保证依赖树可重现。
- 未发现私有仓库、代理或安全扫描相关的依赖管理配置。
