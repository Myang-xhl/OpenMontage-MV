### OpenMontage-MV
- 定义：基于 OpenMontage 的单用途分支项目，专门用于将 ASS 卡拉OK歌词文件转换为完整的音乐视频。项目遵循单一管道设计，只处理一个视频提供商和一个渲染运行时（ffmpeg）。
- 别名：OM-MV、OpenMontage Music Video

### Backlot
- 定义：项目的看板服务器，提供可视化的项目管理界面和实时状态更新。包含 Studio 工作台和 Board 看板两种界面，用于监控 MV 生产流水线的各个阶段。
- 别名：看板、board

### Pipeline Manifest
- 定义：定义 MV 生产流水线的配置文件，包含阶段顺序、工具依赖、质量门控和检查点策略。项目使用 `pipeline_defs/music-video.yaml` 作为标准配置。
- 别名：流水线清单、manifest

### Director Skill
- 定义：每个流水线阶段的指导文档，定义了该阶段的工作流程、输入输出格式和质量标准。项目包含 idea、proposal、storyboard、asset、edit、compose、publish 七个阶段的 director skill。
- 别名：导演技能、director

### Checkpoint Protocol
- 定义：项目阶段的状态管理机制，记录每个阶段的执行状态（completed/failed/awaiting_human/in_progress）和元数据，用于进度跟踪和恢复。
- 别名：检查点协议、checkpoint

### ASS Karaoke File
- 定义：卡拉OK歌词文件格式，包含歌词文本、时间戳和样式信息。项目以此作为 MV 生产的核心输入，驱动整个流水线的分析和生成过程。
- 别名：ASS 文件、karaoke file

### Storyboard-only Delivery
- 定义：当缺少歌曲音频时的降级交付模式，只生成分镜脚本而不制作完整 MV。在 proposal 阶段明确记录此降级决策。
- 别名：仅分镜交付、storyboard delivery

### Seedance 2.0
- 定义：字节跳动的多模态视频+音频模型，项目首选的高级视频生成模型。支持文本到视频、图像到视频、参考条件生成等多种操作模式。
- 别名：seedance、ByteDance Seedance

### Preflight Check
- 定义：生产前的强制预检流程，验证所有必需的工具和环境变量是否就绪。包括 Yinghe Video API Key、FFmpeg 安装、输入素材等检查项。
- 别名：预检、preflight
