# Character Library

Drop character files here. Each character is:

- a Markdown file describing the character (must include the `适配歌曲风格` field —
  see `.agents/skills/mv-storyboard/SKILL.md` Step 4 for the exact format), and
- optionally a PNG reference image (e.g. `015.png`) that the assets stage binds
  for cross-shot character consistency.

Users may also supply custom characters in the SKILL.md custom format.
